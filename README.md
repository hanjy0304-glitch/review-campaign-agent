# 체험단 에이전트 (review-campaign-agent)

블로그·인스타그램 체험단의 **선정 결과, 글 작성 마감일, 방문일**을 텔레그램으로 알려주고, 모든 체험단을 Notion 표 하나에서 관리하는 도구입니다. 여러 체험단 사이트의 안내가 흩어져 있어서 마감을 놓치는 일을 막기 위해 만들었습니다.

*English summary: tracks Korean 체험단 (sponsored review campaigns) across sites, keeps them in one Notion table, and sends Telegram alerts for selection, review deadlines and visit dates. Runs on GitHub Actions; no server needed.*

## 이런 알림이 옵니다

```
🎉 선정됐어요
가게이름 (리뷰노트)
글 마감일 10/25 (D-3)

⏰ 글 마감 D-1
가게이름 (리뷰노트)
마감 10/25

📍 방문 오늘!
가게이름 (리뷰노트)
방문일 10/20
```

| 알림 | 언제 오나요 |
|---|---|
| 선정 | 표에 선정된 체험단이 새로 들어왔을 때 |
| 글 마감 | 마감 3일 전, 1일 전, 당일 (바꿀 수 있습니다) |
| 방문 | 방문일 1일 전, 당일 |
| 입력 요청 | 글마감일이 비어 있을 때, 방문형인데 방문일이 비어 있을 때 |
| 마감 지남 | 마감일이 지났는데 아직 작성완료가 아닐 때 |
| 오늘의 할 일 요약 | 매일 오전 9시 무렵, 작성하지 않은 체험단을 마감 임박 순으로 |

날짜는 모두 **한국시간** 기준입니다. 알림은 하루 두 번(오전 9시, 오후 6시 무렵) 확인해서 보냅니다.

## 시작하기 (약 20~30분)

**준비물 (모두 무료):** GitHub 계정, 텔레그램 앱, Notion 계정

| 단계 | 하는 일 | 설명 문서 |
|---|---|---|
| 1단계 | 내 저장소 만들기 | 아래 설명 |
| 2단계 | 텔레그램 봇 만들고 봇 토큰 받기 | [텔레그램 연결](docs/telegram-setup.md) 1번 |
| 3단계 | Notion 연결 만들고 시크릿 키 받기, 페이지에 연결 허용하기 | [Notion 연결](docs/notion-setup.md) 1~3번 |
| 4단계 | 받은 값 2개(봇 토큰, Notion 시크릿 키)를 GitHub 에 등록하기 | [값 등록](docs/secrets-setup.md) |
| 5단계 | 버튼을 눌러 chat_id 확인하고 Notion 표 만들기, 나온 값 2개 추가 등록하기 | [텔레그램 연결](docs/telegram-setup.md) 2번, [Notion 연결](docs/notion-setup.md) 4번 |
| 6단계 | 연결 확인 | 아래 설명 |

### 1단계. 내 저장소 만들기
1. 이 페이지 위쪽의 **Use this template** → **Create a new repository** 를 누릅니다.
2. 저장소 이름을 정하고, 공개 범위는 **Private(비공개)** 을 선택합니다. 알림 기록이 다른 사람에게 보이지 않게 하려면 비공개를 권합니다.
3. **Create repository** 를 누릅니다. 이후 모든 작업은 새로 만든 내 저장소에서 합니다.

### 6단계. 연결 확인
내 저장소의 **Actions** 탭 → 왼쪽 **연결 확인** → **Run workflow** 에서 동작을 골라 실행합니다. 처음 Actions 탭을 열었을 때 활성화 버튼이 보이면 눌러 주세요.

| 고르는 동작 | 확인하는 것 | 성공하면 |
|---|---|---|
| `telegram-test` | 텔레그램 연결 | 텔레그램에 테스트 메시지가 옵니다 |
| `notion-check` | Notion 연결 | 로그에 오늘 올 알림 미리보기가 나옵니다 (실제로 보내지는 않음) |

`notion-check` 에서 알림이 보이게 하려면 Notion 표에 **체험단명, 글마감일(오늘이나 내일)** 을 넣은 테스트 행을 하나 만든 뒤 실행하세요. 두 확인이 끝나면 설정은 끝입니다. 이후에는 자동으로 하루 두 번 실행됩니다.

문제가 생기면 [문제 해결](docs/troubleshooting.md)을 보세요.

## 매일 쓰는 법
현재는 자동 수집이 없어서, 선정되면 Notion 표에 새 행을 만들고 **체험단명, 글마감일**을 입력합니다. 방문형이면 예약 후 **방문일**도 입력하세요. 체험을 마치면 **진행단계**를 `체험완료`, 후기를 올리면 `작성완료`로 바꿉니다. 칸별 설명은 [Notion 연결](docs/notion-setup.md)의 "표 사용법"에 있습니다.

## 지원하는 체험단 사이트와 현재 한계
- 사이트 목록은 [config/sites.yaml](config/sites.yaml)에 있습니다 (강남맛집, 리뷰노트, 디너의여왕, 리뷰플레이스, 미블, 체험뷰, 포포몬, 아싸뷰, 슈퍼멤버스, 레뷰, 서울오빠, 클라우드리뷰, 티블, 놀러와, 링블, 어디야체험단, 리워딩스, 스타일씨).
- **현재는 사이트에서 선정 내역을 자동으로 가져오지 않습니다 (개발 중).** 임시로 선정된 체험단을 Notion 표에 직접 입력해야 하고, 입력한 뒤의 마감·방문 알림은 자동입니다. 자동 수집이 추가되면 직접 입력이 필요 없어지도록 만들고 있습니다.
- 목록에 없는 사이트도 표의 **사이트** 칸에 `기타` 를 고르거나 옵션을 추가해서 쓸 수 있습니다.

## 개인정보와 보안
- 텔레그램 봇 토큰과 Notion 시크릿 키는 GitHub Secrets 에만 등록하세요. 파일이나 채팅에 적지 마세요.
- 저장소를 Private 으로 만들면 알림 실행 기록(Actions 로그)이 다른 사람에게 보이지 않습니다.
- 이 저장소에는 개인 정보를 올리지 않도록 막는 장치가 들어 있습니다 (`.gitignore`, 커밋 전 검사 `.githooks/pre-commit`). 코드를 수정하는 개발자는 `git config core.hooksPath .githooks` 로 켜 주세요.

## 개발자용
- Python 3.10 이상. 저장소 루트에서 실행하세요 (`pip install` 로 설치하는 방식이 아닙니다).
- 설치와 테스트: `pip install -r requirements.txt pytest` → `python -m pytest`
- 설정 질문 실행: `python -m review_campaign_agent setup` (옵션 없이 실행하면 사용하는 체험단 사이트를 가장 먼저 묻습니다)
- 명령 목록: `python -m review_campaign_agent --help`
- AI 코딩 에이전트가 설치를 도울 때의 지침은 [AGENTS.md](AGENTS.md)에 있습니다.

## 안내
비공식 도구이며 각 체험단 사이트와 관련이 없습니다. 사이트 이용약관을 지킬 책임은 사용자에게 있습니다. 라이선스는 추후 추가할 예정입니다.
