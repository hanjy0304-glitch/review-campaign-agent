# 체험단 수집기 (크롬 확장, 개발 중)

내 PC 크롬에서 **이미 로그인된** 체험단 사이트의 "진행중 체험단"을 읽어 내 Notion 표(`체험단 관리`)에 저장합니다.
선정 알림과 마감 알림은 기존 GitHub Actions(`run.yml`)가 Notion을 읽어 텔레그램으로 보냅니다.

- 사이트 아이디·비밀번호·쿠키를 읽거나 저장하거나 전송하지 않습니다. 크롬에서 평소처럼 로그인해 두면 됩니다.
- 이 확장이 쓰는 값은 Notion 연동 토큰(위 `docs/notion-setup.md`의 2번에서 만든 시크릿 키)과 표 주소뿐이며, 이 컴퓨터의 크롬(`chrome.storage.local`)에만 저장됩니다.
- 지원 사이트: 리뷰노트(`진행중` 목록), 디너의여왕·리뷰플레이스·서울오빠·강남맛집·포포몬(마이페이지, 실측 전 experimental).
  새 선정과 글 마감일(오늘 + `D-n`, 한국시간)을 저장합니다.
  사이트 목록은 `src/sites.js` 한 곳에 있고, 새 사이트 추가 절차는 [../docs/add-site.md](../docs/add-site.md)에 있습니다.
- 아직 안 하는 것: 리뷰 등록 완료·취소 감지, 디너의여왕·리뷰플레이스·서울오빠·강남맛집의 로그인 화면 실측(공개 화면 구조로 짠 파서라 실제 '내 신청' 화면과 다를 수 있음), 일반 유저용 설치(크롬 웹스토어).

## 개발자용: 설치와 테스트

```bash
cd extension && npm ci && npm test
```

크롬 → `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드" → 이 `extension` 폴더 선택.
확장 옵션 화면에서 토큰·표 주소를 저장하고 `지금 수집`을 누릅니다.

## 아직 실제로 확인하지 못한 것

- 실제 리뷰노트 화면에서의 수집 (테스트는 가짜 카드 HTML)
- 백그라운드 탭에서 무한 스크롤이 끝까지 불러와지는지
- Notion API 호출이 확장에서 CORS 없이 동작하는지 (host_permissions 설정은 했음)
- 3시간 주기 알람 동작
