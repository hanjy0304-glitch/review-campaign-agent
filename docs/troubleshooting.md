# 문제 해결

실행 결과는 **Actions** 탭 → 실행 항목 → **connections**(또는 **run**) → **Run** 에서 확인합니다. 아래에서 화면에 나온 문구와 같은 항목을 찾으세요.

## 실행 자체가 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| Actions 탭에 `연결 확인` 이 안 보임 | Actions 가 꺼져 있음 | Actions 탭의 "워크플로우를 활성화" 버튼을 누르세요 |
| 실행이 빨간색 X 로 끝남 | 아래 문구 중 하나가 로그에 있음 | 로그 맨 아래 문구를 확인하세요 |
| 실행 결과가 "건너뜁니다" | `NOTION_TOKEN` 이 등록되지 않음 | [값 등록](secrets-setup.md)에서 등록하세요 |

## 로그에 나오는 문구별 해결

| 로그 문구 | 원인 | 해결 |
|---|---|---|
| `환경변수 ... 가 비어 있습니다` | 해당 이름의 Secret 이 없거나 이름 철자가 다름 | Secrets 목록에서 이름을 확인하세요. 대소문자와 밑줄이 정확해야 합니다 |
| `Notion API 오류 401` | `NOTION_TOKEN` 값이 잘못됨 | 시크릿 키를 다시 복사해 같은 이름으로 다시 등록하세요 |
| `Notion API 오류 404` 또는 `object_not_found` | 연결이 그 페이지에 허용되지 않음 | [Notion 3번](notion-setup.md): 페이지의 `···` → 연결에서 만든 연결을 추가하세요 |
| `Notion 링크에서 페이지 id 를 찾지 못했습니다` | 복사한 주소가 페이지 주소가 아님 | 페이지에서 공유 → 링크 복사로 다시 복사하세요 |
| `Notion API 오류 400` (notion-check 중) | `NOTION_DATABASE_ID` 가 표 id 가 아님 | `notion-init` 로그에 나온 표 id 를 다시 등록하세요 |
| `텔레그램 오류 401` | `TELEGRAM_BOT_TOKEN` 값이 잘못됨 | BotFather 가 준 토큰을 다시 복사해 등록하세요 |
| `받은 메시지가 없습니다` | 봇에게 메시지를 보내지 않았음 | 텔레그램에서 내 봇에게 아무 메시지를 보낸 뒤 다시 실행하세요 |
| `텔레그램 오류 400 ... chat not found` | `TELEGRAM_CHAT_ID` 가 틀리거나, 봇에게 먼저 메시지를 보내지 않음 | 봇에게 메시지를 보낸 뒤 `telegram-chat-id` 를 다시 실행해 값을 확인하세요 |

## 알림이 안 올 때

1. Actions 탭에서 `run` 이 하루 두 번(한국시간 오전 9시, 오후 6시 무렵) 실행됐는지 확인하세요. GitHub 의 예약 실행은 몇 분 늦어질 수 있습니다.
2. `연결 확인` 의 `notion-check` 를 실행해 미리보기에 내 체험단이 나오는지 보세요.
3. 미리보기에 나오지 않으면 표에서 **진행단계**가 `작성완료` 가 아닌지, **선정상태** 가 `탈락` 이나 `신청` 이 아닌지, **글마감일** 이 입력됐는지 확인하세요.
4. 알림이 한 번 온 뒤에는 같은 알림이 다시 오지 않습니다. 다시 받고 싶으면 그 행의 **알림이력** 칸을 비우세요.
5. 저장소를 오래 사용하지 않으면 GitHub 이 예약 실행을 멈출 수 있습니다. Actions 탭에서 `run` 이 꺼져 있다면 다시 활성화하세요.
