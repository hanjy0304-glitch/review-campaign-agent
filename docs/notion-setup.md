# Notion 연결과 체험단 관리 표 만들기

**이 단계에서 하는 일:** 에이전트가 Notion 에 접속할 수 있게 연결을 만들고, 체험단 정보를 적을 표를 만듭니다.
**끝나면 얻는 것:** Notion 시크릿 키, 체험단 관리 표, 표 id. 키와 id 는 [값 등록](secrets-setup.md)에서 등록합니다.
**걸리는 시간:** 약 10분
**필요한 것:** Notion 계정 (https://www.notion.so 에서 무료 가입)

> Notion 화면의 메뉴 이름은 업데이트로 달라질 수 있습니다. 아래 이름과 다르면 비슷한 이름의 메뉴를 찾아보세요.

## 1. 표를 넣을 빈 페이지 만들기 (README 3단계에서 진행)
Notion 왼쪽 사이드바에서 새 페이지를 만들고 이름을 정합니다 (예: `체험단`). 표가 이 페이지 안에 만들어집니다. 기존에 쓰던 페이지에 만들어도 되지만 새 빈 페이지를 권합니다.

## 2. Notion 연결 만들고 시크릿 키 받기
에이전트가 Notion 에 접속할 때 쓰는 연결입니다.

1. https://www.notion.so/profile/integrations 를 엽니다.
2. **새 통합** (New integration) 을 누르고 이름을 입력합니다 (예: `체험단 에이전트`). 종류는 **내부(Internal)** 입니다.
3. 권한은 **콘텐츠 읽기**, **콘텐츠 업데이트**, **콘텐츠 삽입** 을 켭니다.
4. 저장하면 **시크릿 키**가 표시됩니다 (`ntn_` 또는 `secret_` 으로 시작). 복사해 두세요.
5. [값 등록](secrets-setup.md)에서 이 값을 `NOTION_TOKEN` 이라는 이름으로 등록합니다.

## 3. 1번 페이지에서 연결 허용하기
**이 단계를 빠뜨리면 `object_not_found` 오류가 납니다.** 연결은 허용한 페이지에만 접근할 수 있습니다.

1. 1번에서 만든 페이지를 엽니다.
2. 오른쪽 위 `···` 메뉴 → **연결(Connections)** 에서 2번에서 만든 연결을 추가합니다. 확인 창이 나오면 허용합니다.

## 4. 표 만들기 (README 5단계에서 진행)
1. 1번 페이지에서 **공유(Share)** → **링크 복사** 를 눌러 페이지 주소를 복사합니다.
2. `NOTION_TOKEN` 이 [등록](secrets-setup.md)되어 있어야 합니다. 아직 안 했다면 먼저 등록하세요.
3. GitHub 내 저장소의 **Actions** 탭 → 왼쪽 **연결 확인** → **Run workflow** 를 누릅니다.
4. 동작을 `notion-init` 으로 선택하고, **notion_parent** 칸에 복사한 페이지 주소를 붙여넣은 뒤 **Run workflow** 를 누릅니다.
5. 1분쯤 기다려 초록색 체크가 표시되면 그 실행을 눌러 **connections** → **Run** 을 엽니다. 맨 아래에 표 주소와 **표 id** (`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` 모양)가 나옵니다.
6. 표 id 를 `NOTION_DATABASE_ID` 라는 이름으로 등록합니다.
7. Notion 페이지를 새로고침하면 `체험단 관리` 표가 생겨 있습니다.

## 5. 보기 추가 (선택, 1분)
보기는 Notion 에서 직접 추가해야 합니다. 추가하지 않아도 알림은 정상적으로 옵니다. 표 위의 `+` 로 추가하세요.

| 보기 이름 | 종류 | 설정 |
|---|---|---|
| 마감 임박 | 표 | 필터: 진행단계가 작성완료가 아님 / 정렬: 글마감일 오름차순 |
| 진행 현황 | 보드 | 그룹: 진행단계 |
| 마감 캘린더 | 캘린더 | 날짜 기준: 글마감일 |
| 방문 캘린더 | 캘린더 | 날짜 기준: 방문일 |

## 표 사용법

> **현재는 체험단 사이트에서 선정 내역을 자동으로 가져오는 기능이 아직 없습니다 (개발 예정).** 그래서 임시로 선정된 체험단을 표에 직접 입력해야 합니다. 자동 수집이 추가되면 이 입력은 필요 없어지고, 에이전트가 행을 만들어 줍니다.

선정되면 표에 새 행을 만들고 아래 순서로 입력합니다.

1. **체험단명**, **글마감일** 을 입력합니다. 이 두 칸만 있어도 마감 알림이 옵니다. 사이트는 입력하지 않아도 됩니다.
2. 방문형이면 **유형** 을 `방문형` 으로 고르고, 예약을 잡은 뒤 **방문일** 을 입력합니다. 방문 전날과 당일에 알림이 옵니다.
3. 체험을 마치면 **진행단계** 를 `체험완료` 로 바꿉니다. 방문 알림이 멈춥니다.
4. 후기를 올리면 **진행단계** 를 `작성완료` 로 바꿉니다. 이 체험단의 모든 알림이 멈춥니다.

### 칸 설명

**직접 입력하는 칸**

| 칸 | 설명 |
|---|---|
| 체험단명, 사이트 | 체험단 이름과 신청한 사이트 |
| 글마감일 | 후기 작성 마감일. 마감 알림의 기준입니다 |
| 방문일 | 방문 예약일. 입력해야 방문 알림이 옵니다 |
| 유형 | 방문형이면서 방문일이 비어 있으면 "방문일을 입력해 주세요" 알림이 옵니다 |
| 진행단계 | `진행필요` → `예약완료` → `체험완료` → `작성완료` |
| 페이백, 제공내역, 방문가능시간, 메모 | 기록용. 에이전트가 수정하지 않습니다 |

**에이전트가 관리하는 칸 (수정하지 않아도 됩니다)**

| 칸 | 설명 |
|---|---|
| 선정상태 | 직접 입력한 행은 비워 두면 선정으로 처리합니다 |
| 선정일 | 자동 수집된 행에만 채워집니다 |
| 남은일수 | 글마감일까지 남은 날 수 (한국시간 기준, 하루 두 번 갱신) |
| 입력방식, 고유키, 알림이력 | 같은 알림이 반복되지 않게 하는 기록. 지우면 알림이 한 번 더 올 수 있습니다 |

자동 수집이 추가된 사이트는 선정되면 에이전트가 행을 만들어 줍니다. 그 행에서는 방문일, 진행단계만 직접 바꾸면 됩니다.

## 개발자용: 내 컴퓨터에서 실행하기
`.env` 에 `NOTION_TOKEN` 을 넣고 실행합니다.

```
python -m review_campaign_agent notion-init --parent "복사한 페이지 링크"
```

안 될 때는 [문제 해결](troubleshooting.md)을 보세요.
