# Notion 체험단 관리 표 만들기

에이전트가 읽고 쓰는 표를 내 Notion에 한 번에 만드는 방법입니다. 표 양식은 에이전트가 만들어 주니 직접 칸을 만들 필요가 없습니다.

## 1. 빈 페이지 만들기
Notion에서 새 페이지를 하나 만듭니다. 이름은 자유입니다 (예: `체험단`). 이 페이지 안에 표가 생깁니다.

## 2. Notion 연결(integration) 만들기
1. https://www.notion.so/profile/integrations 에서 새 연결을 만듭니다. 종류는 "내부(Internal)"입니다. (화면 이름은 Notion 업데이트로 달라질 수 있습니다.)
2. 권한은 "콘텐츠 읽기 / 업데이트 / 삽입"을 켭니다.
3. 만들어진 **시크릿 키**를 복사해 `NOTION_TOKEN` 으로 `.env` 파일 또는 GitHub Secrets 에 넣습니다. 채팅이나 코드에 붙여넣지 마세요.

## 3. 페이지에 연결 허용하기
1번에서 만든 페이지 오른쪽 위 `···` → **연결(Connections)** → 2번에서 만든 연결을 추가합니다. 이 단계를 빼먹으면 `object_not_found` 같은 오류가 납니다.

## 4. 표 자동 생성
페이지 링크를 복사해서 실행합니다.

```
python -m review_campaign_agent notion-init --parent "복사한 페이지 링크"
```

출력되는 표 주소를 열어 확인하고, 함께 나온 id 를 `NOTION_DATABASE_ID` 로 저장합니다.

## 5. 보기(View) 추가 (직접, 1분)
Notion API로는 보기를 만들 수 없어서 표 위의 `+ 보기 추가`로 만드세요.

| 보기 | 종류 | 설정 |
|---|---|---|
| 마감 임박 | 표 | 필터: 진행단계 ≠ 작성완료 / 정렬: 글마감일 오름차순 |
| 진행 현황 | 보드 | 그룹: 진행단계 |
| 마감 캘린더 | 캘린더 | 날짜 기준: 글마감일 |
| 방문 캘린더 | 캘린더 | 날짜 기준: 방문일 |

## 칸 설명: 누가 입력하나요?

**내가 입력하는 칸**

| 칸 | 설명 |
|---|---|
| 체험단명, 사이트 | 직접 입력하는 행에서만 (자동 수집된 행은 에이전트가 채움) |
| 글마감일 | 선정 안내에 적힌 리뷰 작성 마감일. 가장 중요한 칸 |
| 방문일 | **예약을 잡은 뒤 직접 입력**. 입력하면 방문 전날·당일에 알림이 옵니다 |
| 유형 | `방문형`으로 두고 방문일이 비어 있으면 "방문일을 입력해 주세요" 알림이 옵니다 |
| 진행단계 | `진행필요` → `예약완료` → `체험완료` → `작성완료`. **체험완료**로 바꾸면 방문 알림이 멈추고, **작성완료**로 바꾸면 모든 알림이 멈춥니다 |
| 페이백, 제공내역, 방문가능시간, 메모 | 자유 기록용. 에이전트는 건드리지 않습니다 |

**에이전트가 관리하는 칸** (수정하지 않아도 됩니다)

| 칸 | 설명 |
|---|---|
| 선정상태 | 신청 / 선정 / 탈락. 직접 입력한 행은 비워 두면 "선정"으로 봅니다 |
| 선정일, 남은일수 | 남은일수는 글마감일까지 남은 날 (한국시간 기준, 하루 두 번 갱신) |
| 입력방식, 고유키, 알림이력 | 중복 방지용 내부 기록. 지우면 알림이 한 번 더 올 수 있습니다 |

## 자동 수집이 없는 사이트는 이렇게
선정 문자를 받으면 표에 새 행을 만들고 **체험단명, 사이트, 글마감일**(방문형이면 유형·방문일도)만 적으세요. 알림은 자동 수집된 행과 똑같이 옵니다.
